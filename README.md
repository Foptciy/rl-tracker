# RL Tracker

[Download for Windows](https://github.com/Foptciy/rl-tracker/releases/latest) · [Report an issue](https://github.com/Foptciy/rl-tracker/issues)

Automatic Rocket League match history, MMR trends, live win predictions, scoreboard overlays, player stats, teammate history, and Win Songs.

Download **RLTracker-Setup** for Windows 10/11 (64-bit). A portable ZIP is also available. The desktop app checks for updates and installs verified releases when matches, songs, and editing finish. Manage updates in Settings.

Win Songs includes song uploads, waveform trimming, random selection, tournament warmup playlists, fades, kickoff timing, and Spotify volume controls. Microsoft Edge WebView2 Runtime is required for the song editor and is normally installed with Windows.

Match history is stored in `%LOCALAPPDATA%\RL Tracker`. Existing Win Songs libraries remain in `%LOCALAPPDATA%\WinSongs`. Updates and uninstalling preserve those folders. Automatic deletion of game recordings is disabled by default.

This repository hosts downloads, release notes, and issue reports. Development source and player data are not published here. GitHub-generated source archives contain this documentation only.
