# RL Tracker

[Download for Windows](https://github.com/Foptciy/rl-tracker/releases/latest) · [Report an issue](https://github.com/Foptciy/rl-tracker/issues)

Automatic Rocket League match history, MMR trends, live win predictions, scoreboard overlays, player stats, teammate history, and Win Songs.

Download **RLTracker-Setup** for Windows 10/11 (64-bit). A portable ZIP is also available. The desktop app checks for updates at startup and every hour, then installs verified releases when matches, songs, and editing finish. Manage updates in Settings.

Win Songs includes song uploads, waveform trimming, random selection, tournament warmup playlists, fades, kickoff timing, and Spotify volume controls. The song editor and desktop runtime are included in the download.

The app can read your signed-in Rocket League account from the local game log; you can also set your player name in Settings. If Rocket League's Stats API is disabled, a popup offers **Enable Stats API**. After enabling it, fully close and restart Rocket League. Keep RL Tracker open while playing to record matches automatically.

The HUD is enabled by default on new profiles and appears while Rocket League is focused. For an existing profile, open **Overlay studio** and select **Launch overlay** if it is hidden. Match the interface scale to Rocket League's setting. Use borderless/windowed mode for desktop overlays.

Match history, recordings, settings, and songs are stored in `%LOCALAPPDATA%\RL Tracker`. Updates and uninstalling preserve this data. Automatic deletion of game recordings is disabled by default. Personal match history and audio files are not included in the installer.

This repository hosts downloads, release notes, and issue reports. Development source and player data are not published here. GitHub-generated source archives contain this documentation only.
